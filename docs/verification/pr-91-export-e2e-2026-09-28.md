# PR #91 export disk-path verification (2026-09-28)

## Reproduce

Run on macOS arm64 with Xcode's Swift toolchain and this repository's resolved SwiftPM dependencies and bundled libgit2 libraries:

```sh
CLANG_MODULE_CACHE_PATH=/private/tmp/aipulse-pr91-module-cache \
SWIFTPM_MODULECACHE_OVERRIDE=/private/tmp/aipulse-pr91-module-cache \
swift test --filter DataExportTests --disable-automatic-resolution \
  > /private/tmp/aipulse-pr91-export-e2e.log 2>&1
```

The reproducible input is the in-memory SQLite fixture in `Tests/DataExportTests.swift` (usage events, balances `12.5`, `-0.125` and `42.0`, code changes and commits). The disk-path test runs the production section readers and writer, reads the resulting CSV/JSON files, makes three exports with one fixed timestamp, changes the database between exports and checks that the first export remains unchanged. Another test induces a failed second CSV write and checks that the incomplete directory is removed. The fixture uses a unique system temporary directory and removes it after the test.

## Observed result

The command exited 0 on 2026-09-28: 5 `DataExportTests` passed, 0 failed. The generated log is `/private/tmp/aipulse-pr91-export-e2e.log`; rerunning the command regenerates it. The tests confirm fractional REAL values in CSV and JSON, INTEGER and NULL values in the usage table, CSV escaping, unique folders for same-second exports, preservation of previous files, and cleanup on a write failure.

This exercises the app's database-to-disk export code path. It does not exercise the Settings button or Finder UI, and it does not use the user's database.
