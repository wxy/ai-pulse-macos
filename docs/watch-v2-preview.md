# Watch 2.0 三圈仪表盘

在 `Suites/AIPulse_Suites.xcodeproj` 中选择 `AIPulse_watchOS`，运行到手表或 Watch 模拟器。iPhone target 已恢复 Watch App 的嵌入与依赖，因此重新运行 iPhone 包后可安装配对手表应用。继续使用既有 bundle ID 与 `iCloud.com.wxy.aipulse` 容器，无需新建数据库或 target。

外圈显示今日词元，中圈显示今日代码新增加删除行数，内圈显示当前强度。左上、右上显示事实数量，下方显示相对平常的倍数；下方数值在上、标签在下，左右分别对齐。中央显示当前强度及强度观测时间。点击中央进入数据说明和手动同步。

平常是最近 28 天已观测活跃日的中位数估算，各指标至少需要 7 个样本日。历史查询失败、样本不足、基准为零或缺失时不计算进度；空白日不能证明完整观测，因此不补零。这里不承诺全天完整采集，也不表示额度、目标或效率。使用 Mac 30 天摘要及其时区，剔除当前日。无今日摘要或跨日旧缓存不冒充今日数据；未观测到仓库变化时显示不可用。

词元和行数超过满圈时保留完整深色圈，叠加下一圈的亮弧和实心端点；整数圈仍显示完整圈。强度来自 activity 信号 normalized / 3，3 是现有高强度分级边界；最大满圈，不多圈，过期后变灰。灰环用于未知而非零值。

当前强度独立读取 `DashboardCache_v2/current-pulse`。前台每分钟读取今日摘要与强度；激活和手动同步读取 today、30d 与强度。网络失败保留缓存，不延长强度有效期。Mac 的七分钟云端有效期保持不变。

## 演示与验证

只有 Debug 显式运行参数 `--watch-preview` 才装载合成数据，首页标记“演示”，不连接云端、不写缓存。默认演示展示 2.4× 词元和 3.0× 行数。可追加 `--watch-no-baseline` 检查历史不足，或 `--watch-expired` 检查过期；Release 不接受演示模式。

5 项数据投影测试通过，覆盖中位数、缺失样本、查询失败、新增加删除、整数/多圈和强度过期。40mm 与 46mm 模拟器均运行检查，Watch Debug / Release 构建通过；iPhone 与嵌入 Watch 的联合 Debug 构建通过。普通 Watch 模拟器启动显示无观测且没有崩溃；真实 Watch 的 Apple 账户、CloudKit 往返和佩戴状态尚需验收。

圈图使用完整屏幕宽度的 93%，不再按扣除文字区后的高度缩小。沿用旧版忽略安全区、四角覆盖的布局，数据贴近屏幕四角，中央内容随圈图圆心定位。恢复旧版空工具栏布局后，40mm 与 46mm 模拟器均显示顶部居中的系统时间，移除自绘时间以避免重复；最低版本维持 watchOS 10。真机佩戴与待机状态仍需验收。

旧 iPhone 与 Watch Widget 源码和 target 保留，暂不嵌入安装包。macOS、iPhone、Watch 的小组件会在后续统一重新设计，本次不改造其功能。
