# AI Pulse 2.0 — 消费脉搏

> 2026-09-17 · 现行规则；本轮 macOS 目标已完成，人工验收由用户确认，采集恢复运行验收豁免；尚未正式发布。
> 用户确认优先；来源语义详见 [数据事实](data-facts-and-surfaces.md)，执行状态详见 [macOS 收口计划](macos-v2-closure-plan.md)。
> 后续独立改造：当前脉搏仅词元驱动，菜单栏恢复火焰，Dock 保留机器人并以固定状态灯共用颜色与消费短亮时钟；规则与本轮验证边界见 [事实优先的统一脉搏](fact-first-unified-pulse.md)。既有确认不代替本次新视觉验收。

## 1. 目标与边界

让用户感到自己持续在 AI 上投入、强度正在变化，并看到伴随的本地成果。它像脉搏，不是账单、精确计量器或投入产出价值评判器。

- 不承诺跨服务商全量用量；不追逐套餐计费规则。
- 不做词元估价、订阅日摊销、预测、每会话或每行成本。
- 不把词元、币种、额度百分比、代码行数直接相加。
- 不以模型名称推断实际付款账户或套餐。
- 2.0 不保留 1.0 展示、传输与派生模型兼容；用户原始历史保留。
- macOS 完整运行与验收前，暂停手机、手表和 Widget 的开发与改进。

## 2. 事实、背景与未知

本地日志是主要活动来源。输入、缓存和推理分项服从各来源实际语义，所有查询与反馈共用归一规则，不按通用假设补数。

余额／累计用量采样提供原币区间净下降，不是本应用逐笔花费；充值、退款、共享账户及间隔影响解释。显示区间与原币，换算必须有明确依据；未知币种不按美元 1:1 换算。

月费仅是用户声明的固定投入背景，不是今日／本周支付金额；无需账期起点或周期，不要求登记所有套餐。模型目录只含名称和供应商，不保存价格。

额度窗口独立显示，使用源时间、重置时间与有效期；复制或重读缓存不能续期。模型家族只是适用性过滤，不证明订阅付款。

缺失分项、不可读日志、查询失败、过期与零活动不同。未知不能变成健康零；部分事实说明覆盖范围。支持的本地日志不等于账户完整活动。

## 3. 当前脉搏与周期

当前脉搏有独立观察时间和有效期，只由已观察词元活动驱动；余额下降、额度压力与代码／提交独立呈现，不改变等级。活动停止后回落，余波明确称“投入回落中”；无有效观察显示未知，不冒充休息。历史样本不足使用明确的固定参考，不称个人平时习惯；事实总量不使用强度指数。

今日、本周、30 天是三份独立内存快照，切换只选择展示对象，异步刷新不能相互覆盖。快照带周期、时区、日历和粒度；旧派生缓存失效重建。

- 今日按本地小时事实，共用词元／代码时间轴，显示 24 个槽位。
- 本周周一开始，固定七个日槽位；30 天含今日，固定三十个日槽位。
- 跨午夜与夏令时按日历，不假设每日本质上固定 24 小时。
- 顶部均速按完整展示周期计算，不称即时速率或个人平时基线。

## 4. 仪表盘与详情

保留机器人头像，头像不混放订阅和 API 金额。

| 部位 | 表达 |
|---|---|
| 天线／额头 | 居中周期切换、状态提示、所选周期词元总量、会话和活跃情况；全周期均速在会话信息下一行 |
| 左眼 | 工具词元份额 |
| 右眼 | 授权 Git 仓库的增加行＋删除行份额，不是净增长 |
| 鼻子 | 下移、缩短的上小下大梯形，上删下增，高度表示各自在变化行中的比例；增删标签在图外，提交数留白独立显示 |
| 嘴部 | 词元／代码相向分节节奏，独立归一且不重叠 |

无活动保留淡色分节基线；采集未知不能仅靠空图表达。词元／行数用 K、M、G、T，带小数一位；中文称“词元”。

本周嘴部展示21个日位置：前一周7格与后一周7格仅为与无数据一致的淡灰实线基线，中间7格展示本周真实每日活动；不显示三周分组文字、不使用虚线。两侧仅补足视觉密度，不表示相邻周已确认无活动，不读取相邻周数据、不参与峰值或统计。本周均速仍除以7日；今日24小时与30天布局不增加占位。

三个周期都有工具×模型及仓库明细。模型身份包含供应商，同单元格累加；有词元用量的缺失模型和未归属工具可见，仅零词元的未知模型组不占据明细行，不修改原始事件或会话统计。工具×模型表的小矩阵与仓库表一样直接使用可伸展的 Grid，不套横向滚动区；多列按实际容器宽度分配列宽，保留最小可读宽度并横向滚动，不静默截断；折叠保留展开入口与全量合计，不静默丢弃较低用量行。实际可读性由用户确认。圈图明确标注“工具用量（词元）”“仓库变化（行数）”，中心数值另有对应单位。

金额与额度在头像外按事实条件显示，直接标注“账户金额观察”“额度 · 当前窗口”；声明月费仅在 30 天的“每月固定投入”上下文，不进入环图或金额总计。不再使用含糊的“已观察到的事实”大标题，无有效上下文时不保留空说明卡；部分、失败和过期仍明确可见。

账户金额观察独立成卡，仅存在有限且大于零的原币金额时显示。供应商及金额为主信息；采样净下降说明放在卡片标题旁的叹号按钮中，不常驻占据空间。词元分项不完整／完整性未知说明放在额头词元总量旁的叹号按钮中，完整时不显示；演示不伪造覆盖警告。两个按钮均显示手形光标，悬停立即打开锚定提示层，点击固定提示；鼠标可进入提示内容阅读，离开按钮和提示层后短暂延迟关闭，固定提示由普通弹层关闭动作取消。切换说明内容、进入详情或视图消失时关闭并取消延迟任务。不再依赖系统tooltip；额头容器不挂整体说明，日志范围说明仅挂在“本地日志”文字上。实际读取故障仍保持显著，不因金额为空而丢失，配额／固定投入独立展示。鼻梁仅外轮廓四角圆滑，增删填色之间保持直线且无缝连接，高度仍编码比例。

当前采用表格内数据条，而不是额外独立图表：保留数值和斑马纹，在数值单元格内从左向右绘制16%透明度的矩形背景。线性比例为值÷明细最大值，不设置夸大的最小长度。工具×模型按每个数值列内模型的最大值缩放，行合计列单独缩放，底部合计行不画数据条且不参与尺度。仓库词元与提交分别缩放，增加／删除行共享同一个明细最大值；尺度基于全部可显示仓库，不因折叠前5条而改变。零值没有色条、不可用与非有限值不进入条长几何；数值和点击入口保留，背景不截获鼠标事件。两个表格标题的悬停说明解释各自尺度。不同币种金额不混合比较。

2026-09-18明细折叠规则：工具×模型默认显示词元合计最高的5个模型，低用量行通过“显示全部／收起”控制展开；所有工具列保留，合计行始终显示并按全部模型计算，数据条尺度也不随折叠改变。仓库默认5行，合计行同样始终显示，覆盖全部符合显示条件的仓库而不是仅前5行；合计行不绘制数据条。仓库增删行明细与合计统一用K／M／G／T、一位小数显示。任何仓库词元未知时词元合计显示不可用，不把缺失项补成零；代码查询失败时增删和提交合计不可用。折叠不删除事实、不改写快照、不虚构“其他模型”身份。

详情解释会话、词元、模型、仓库和成果，不显示估价或“是否划算”。工具×模型表的工具列名附显著进入图标，是可聚焦的完整按钮；无归属工具不伪造可点击入口。不保留重复下拉菜单。详情在原窗口替换主内容，用“返回仪表盘”箭头返回，保留主视图周期、快照和滚动位置；窗口关闭按钮仍关闭整个窗口。

不再重复显示窗口已有的“仪表盘”名称；今日／本周／30天切换居中放在机器人额头顶部。状态提示在其下一行、位于用量数字上方，使用固定26点高度，不随扫描完成提示出现／消失推动头像；全周期均速位于会话数与活跃日下一行。扫描完成提示五秒后隐藏，失败／过期保留诊断入口；没有临时提示时显示当前词元活动状态。天线附着头像顶部、一起滚动，上方仅保留自身需要的32点空间。详情页仍在返回导航上方展示必要提示，不遮挡返回按钮。

## 5. 仓库与成果

只监控配置开发目录中的真实 Git 根，工作区不是仓库根。同名仓库按规范完整路径区分，提交和代码事实使用仓库＋提交哈希身份。

提交独立于行数，包括空、二进制与合并提交；行数排除合并。扫描当前 HEAD 可达历史、近三十个本地日，沿用仓库 Git 作者配置筛选；未配置作者不能伪称仅统计用户本人。事实和游标同事务，读取失败不推进。

工具 trailer 是弱声明，不是 AI 创作证明；普通人类协作者不是 AI，当前编辑器不能替历史证明工具归属。成果是伴随活动的信号，不代表创作归属或价值。PR／GitHub Release 不统计。

## 6. 菜单、Dock 与收盘

全部出口共用事实范围与格式，当前状态与历史周期汇总分开。首次观察到的近期有效活动可触发反馈；重复回读、历史导入、代码扫描或缓存刷新不制造新消费。

减少动态效果是独立验收门槛，不能以构建通过代替。

收盘保存结构化事实，读取时按当前语言生成，不写旧版句子。内容包括可用词元、原币观察、新鲜额度、授权仓库代码变化与提交；不估价、不摊销、不预测。失败读取保留未知，重叠任务不能重复收盘；通知不另带默认系统声音。

## 7. 声音与免打扰

通知设置与通用平级；系统通知、自动声音、声音包和手动试听分组。

- 消费单次／连续使用对应素材；收盘与可选启动使用提示钟声。
- 一键静音、静音时段和用途统一约束自动播放；静音停止当前声音并取消延迟第二声。
- 每小时上限只约束消费；用途禁用后上限不可编辑。
- 静音时段禁用后起止不可编辑；启动提示默认关闭。
- 试听绕过自动用途／时段，但不绕过全局静音或零音量。
- 素材缺失或播放失败跳过，不用系统蜂鸣绕过独立音量。
- 不承诺自动同步系统专注／勿扰或检测全屏。系统通知由 macOS 管理，不等于应用音效同步。
- 音频本地保留并打包，不上传 GitHub；来源许可文档入库。打包与许可核查是发布门槛。

## 8. 完成条件与历史

测试、Debug／Release 构建、实际运行、CloudKit 权限和用户视觉／听感分别记录，测试通过不单独代表 macOS 达标。本轮自动化与隔离运行证据已记录；用户确认所有剩余人工验收，采集恢复运行验收按要求豁免。具体范围见收口计划，不把用户确认或豁免改写成自动化通过。

CloudKit payload 维持 2.0，实时脉搏与周期快照独立同步；Debug 不写云端，发布环境与权限待验证。暂停客户端可能受新契约影响，不为其保留旧计费契约，也不声称它们可用。
