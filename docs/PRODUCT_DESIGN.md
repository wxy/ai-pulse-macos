# AI Pulse 2.0 — 消费脉搏

> 2026-09-17 · 现行规则；本轮 macOS 目标已完成，人工验收由用户确认，采集恢复运行验收豁免；尚未正式发布。
> 用户确认优先；来源语义详见 [数据事实](data-facts-and-surfaces.md)，执行状态详见 [macOS 收口计划](macos-v2-closure-plan.md)。

## 1. 目标与边界

让用户感到自己持续在 AI 上投入、强度正在变化，并看到伴随的本地成果。它像脉搏，不是账单、精确计量器或投入产出价值评判器。

- 不承诺跨服务商全量用量；不追逐套餐计费规则。
- 不做词元估价、订阅日摊销、预测、每会话或每行成本。
- 不把词元、币种、额度百分比、代码行数直接相加。
- 不以模型名称推断实际付款账户或套餐。
- 2.0 不保留 1.0 展示、传输与派生模型兼容；用户原始历史保留。
- macOS 完整运行与验收前，暂停手机、手表和 Widget 的开发与改进。

## 2. 事实、背景与未知

本地日志是主要活动来源。输入、缓存和推理分项服从各来源实际语义，所有查询与反馈共用归一规则，不按通用假设补数。

余额／累计用量采样提供原币区间净下降，不是本应用逐笔花费；充值、退款、共享账户及间隔影响解释。显示区间与原币，换算必须有明确依据；未知币种不按美元 1:1 换算。

月费仅是用户声明的固定投入背景，不是今日／本周支付金额；无需账期起点或周期，不要求登记所有套餐。模型目录只含名称和供应商，不保存价格。

额度窗口独立显示，使用源时间、重置时间与有效期；复制或重读缓存不能续期。模型家族只是适用性过滤，不证明订阅付款。

缺失分项、不可读日志、查询失败、过期与零活动不同。未知不能变成健康零；部分事实说明覆盖范围。支持的本地日志不等于账户完整活动。

## 3. 当前脉搏与周期

当前脉搏有独立观察时间和有效期，活动停止后回落；无有效观察显示未知，不冒充休息。活动、余额下降、额度压力和有限的输出弱信号独立归一后选择信号，不统一换成金额。

今日、本周、30 天是三份独立内存快照，切换只选择展示对象，异步刷新不能相互覆盖。快照带周期、时区、日历和粒度；旧派生缓存失效重建。

- 今日按本地小时事实，共用词元／代码时间轴，显示 24 个槽位。
- 本周周一开始，固定七个日槽位；30 天含今日，固定三十个日槽位。
- 跨午夜与夏令时按日历，不假设每日本质上固定 24 小时。
- 顶部均速按完整展示周期计算，不称即时速率或个人平时基线。

## 4. 仪表盘与详情

保留机器人头像，头像不混放订阅和 API 金额。

| 部位 | 表达 |
|---|---|
| 天线／额头 | 所选周期词元均速、总量、会话和活跃情况 |
| 左眼／右眼 | 工具／授权 Git 仓库词元份额 |
| 鼻子 | 代码增删和提交 |
| 嘴部 | 词元／代码相向分节节奏，独立归一且不重叠 |

无活动保留淡色分节基线；采集未知不能仅靠空图表达。词元／行数用 K、M、G、T，带小数一位；中文称“词元”。

三个周期都有工具×模型及仓库明细。模型身份包含供应商，同单元格累加，缺失模型和未归属工具可见。当前保留完整矩阵并横向滚动，不静默截断；未来折叠必须包含“其他”且保留总量。实际可读性由用户确认。

金额与额度在头像外按事实条件显示；声明月费仅在 30 天独立上下文，不进入环图或金额总计。

详情解释会话、词元、模型、仓库和成果，不显示估价或“是否划算”。入口有“查看工具详情”文字，不依赖悬停；剩余人工入口验收由用户确认。

## 5. 仓库与成果

只监控配置开发目录中的真实 Git 根，工作区不是仓库根。同名仓库按规范完整路径区分，提交和代码事实使用仓库＋提交哈希身份。

提交独立于行数，包括空、二进制与合并提交；行数排除合并。扫描当前 HEAD 可达历史、近三十个本地日，沿用仓库 Git 作者配置筛选；未配置作者不能伪称仅统计用户本人。事实和游标同事务，读取失败不推进。

工具 trailer 是弱声明，不是 AI 创作证明；普通人类协作者不是 AI，当前编辑器不能替历史证明工具归属。成果是伴随活动的信号，不代表创作归属或价值。PR／GitHub Release 不统计。

## 6. 菜单、Dock 与收盘

全部出口共用事实范围与格式，当前状态与历史周期汇总分开。首次观察到的近期有效活动可触发反馈；重复回读、历史导入、代码扫描或缓存刷新不制造新消费。

减少动态效果是独立验收门槛，不能以构建通过代替。

收盘保存结构化事实，读取时按当前语言生成，不写旧版句子。内容包括可用词元、原币观察、新鲜额度、授权仓库代码变化与提交；不估价、不摊销、不预测。失败读取保留未知，重叠任务不能重复收盘；通知不另带默认系统声音。

## 7. 声音与免打扰

通知设置与通用平级；系统通知、自动声音、声音包和手动试听分组。

- 消费单次／连续使用对应素材；收盘与可选启动使用提示钟声。
- 一键静音、静音时段和用途统一约束自动播放；静音停止当前声音并取消延迟第二声。
- 每小时上限只约束消费；用途禁用后上限不可编辑。
- 静音时段禁用后起止不可编辑；启动提示默认关闭。
- 试听绕过自动用途／时段，但不绕过全局静音或零音量。
- 素材缺失或播放失败跳过，不用系统蜂鸣绕过独立音量。
- 不承诺自动同步系统专注／勿扰或检测全屏。系统通知由 macOS 管理，不等于应用音效同步。
- 音频本地保留并打包，不上传 GitHub；来源许可文档入库。打包与许可核查是发布门槛。

## 8. 完成条件与历史

测试、Debug／Release 构建、实际运行、CloudKit 权限和用户视觉／听感分别记录，测试通过不单独代表 macOS 达标。本轮自动化与隔离运行证据已记录；用户确认所有剩余人工验收，采集恢复运行验收按要求豁免。具体范围见收口计划，不把用户确认或豁免改写成自动化通过。

CloudKit payload 维持 2.0，实时脉搏与周期快照独立同步；Debug 不写云端，发布环境与权限待验证。暂停客户端可能受新契约影响，不为其保留旧计费契约，也不声称它们可用。
